# Recursos de Programación y Robótica — CEDU Montessori

Sitio con las actividades de clase, listo para publicar con GitHub Pages.

## Contenido
- `index.html`: menú de inicio con todas las actividades.
- `algoritmos/index.html`: Algoritmos de todos los días (primaria alta).
- `computadora/index.html`: La computadora y los datos (1° de secundaria).

## Cómo publicarlo (una sola vez)
1. Crea una cuenta en https://github.com (gratis).
2. Botón **New repository**. Nombre sugerido: `robotica-cedu`. Márcalo como **Public**.
3. En el repositorio nuevo: **Add file → Upload files**. Arrastra el contenido de esta carpeta (el `index.html` y las carpetas `algoritmos` y `computadora`) y pulsa **Commit changes**.
4. Ve a **Settings → Pages**. En *Branch* elige `main` y la carpeta `/ (root)`. Guarda.
5. En uno o dos minutos tu sitio queda en: `https://TU-USUARIO.github.io/robotica-cedu/`

## Cómo agregar una actividad nueva
1. Crea una carpeta con un nombre corto (por ejemplo `variables`) y pon dentro su `index.html`.
2. Súbela con **Add file → Upload files**.
3. Agrega una tarjeta nueva en el `index.html` del menú, copiando una de las que ya existen.

## Importante
- El repositorio es público: cualquiera con el enlace puede verlo. No subas listas de alumnos, contraseñas ni datos personales.
